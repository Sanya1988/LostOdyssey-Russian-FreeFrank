# 34 Russian Dreams — EXPERIMENTAL / ЭКСПЕРИМЕНТАЛЬНО

Not standalone. Requires the default language pack **v0.1.0-beta** and official FreeFrank **v1.0.4**.
Close the game, install the clean base pack first, then extract the experimental add-on into the same game folder.
Its `mods/ru/text/.../dr_##_int.xxx.json` files enable 34 translated Dreams (7,802 keys).
It does not replace the base language.ini/fonts and does not unlock or modify saves.
**Severe text overlap, broken wrapping/words and animation limitations remain. No fix is claimed.**
To revert, close the game and replace the entire `mods/ru` folder with a clean copy from the default ZIP.
Do not simply overlay the base ZIP: it cannot remove the add-on's files.
