# Lost Odyssey Russian Language Pack v0.1.0 Beta

Unofficial Russian text language pack for official **FreeFrank v1.0.4, Windows x64**.
**Local release candidate: OWNER_APPROVAL_REQUIRED / LEGAL_REVIEW_REQUIRED.**

[Русский](README.ru.md) · [English](README.en.md) · [Installation RU](docs/INSTALL.ru.md) · [Installation EN](docs/INSTALL.en.md)

Default: **27,951 text keys / 536 resources / 11 LOFONT**; original Dream stories remain as fallback.
Optional experimental add-on: **34 translated Dreams / 7,802 keys**. Combined: 35,753 keys / 570 resources.
Dream layout has serious known overlaps and wrapping issues. It is not fixed or enabled by default.
Internal adapter version 0.5.1 and public package version 0.1.0-beta are different version lines.

No game discs, original archives, game executable, DLLs, saves, native artwork or private Git history are included.
The Russian text is derived from one maintained canonical corpus; this is not a second translation.
