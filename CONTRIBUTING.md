# Reporting issues

Report pack version, official FreeFrank version, disc, location, screen and exact reproduction steps.
Distinguish the default pack from the optional Dream add-on. Crop/redact personal information from any evidence.
Do not upload game data, saved games, achievements, original exports, executable files or full memory dumps.
The maintained canonical corpus is the editorial authority; generated JSON is not a separate translation.
Contributor licensing and the text's legal basis require maintainer review before accepting material for publication.
