# Частые вопросы

## Что скачивать?

Для установки нужен `LostOdyssey-Russian-Language-Pack-v0.1.0-beta.zip` из GitHub Pre-release.
Автоматический GitHub Source code ZIP — снимок репозитория с исходными данными/документацией, не установочный пакет.
Официальный [FreeFrank для Windows x64](https://github.com/freefrank/LostOdysseyRecomp/releases/latest) и собственные данные Lost Odyssey нужны отдельно.

Русификатор предназначен для официального LostOdysseyRecomp от FreeFrank (Windows x64). Проверена работа на версии v1.0.4. Более новые версии могут быть совместимы, но пока не проверены. Обновления FreeFrank могут потребовать адаптации русификатора.

## Куда распаковать?

В папку с `LostOdysseyRecomp.exe`, чтобы получился `mods/ru/language.ini`.
Все файлы ZIP находятся внутри `mods/ru`. Не допускайте `mods/mods` или дополнительного каталога с названием ZIP.
Перед установкой полностью уберите старый `mods/ru` в резервное место за пределами `mods`, затем следуйте INSTALL.

## Как включить русский?

Settings → System → Game language → Russian; сохраните настройку и полностью перезапустите игру.
Press Start, первоначальная настройка и некоторые host-меню пока английские; это известная неполнота.

## Нужно ли начинать заново или переносить сохранения?

Нет. Загрузите существующее сохранение. Языковой пакет не меняет формат/папку сохранений или достижения.
Старое название локации, записанное в save snapshot, может остаться английским.

## Переведены ли сны?

Все 34 текста переведены. Основной ZIP сохраняет оригинальные сны из-за серьёзных проблем раскладки.
Дополнительный `LostOdyssey-Russian-Dreams-v0.1.0-beta-EXPERIMENTAL.zip` включит русский текст, но наложения,
переносы, разрывы слов и нарушения анимации/оформления остаются. Он требует основной пакет той же версии.
Источники дополнения также находятся в optional-разделе репозитория; исходный архив не заменяет установочный ZIP.

## Как убрать дополнение или весь перевод?

Закройте игру. Перенесите всю `mods/ru` за пределы `mods`.
Для отключения только снов заново распакуйте чистый основной ZIP: остальные переводы сохранятся, Dream overrides исчезнут.
Не накладывайте основной ZIP поверх папки дополнения — лишние Dream-файлы от этого не удаляются.
Для удаления всего перевода новую ru-папку не ставьте; выберите другой доступный язык и перезапустите.
Сохранения/достижения/движок удалять не нужно.

## Почему часть магии или интерфейса английская?

Остаются full/short конфликты магии, лимит XMB-пула, неизвестный consumer Special и некоторые переполнения UI.
См. KNOWN_ISSUES. Исчезавшие имена навыков с `%` исправлены в RU 0.5.1; это не текущая общая ошибка Beta.

## Есть ли новый EXE, озвучка, текстуры или сама игра?

Нет: только language.ini, JSON, LOFONT и документация. Графический ru-local-artwork не распространяется.
Другие версии/платформы FreeFrank требуют отдельного ретеста. Проверка была выборочной, не полным прохождением.

## Куда сообщать об ошибке?

В Issues этого проекта после публикации. Укажите версии, диск, локацию, экран и шаги; при необходимости — кадр с удалёнными личными данными.
Не прикладывайте диски, оригинальные архивы, сохранения, токены или полные дампы.
