# Известные проблемы — v0.3.0 Beta

## Серьёзные ограничения

- **Сны:** отдельное EXPERIMENTAL дополнение с 34 рассказами имеет серьёзные наложения фрагментов, разрывы строк/слов и нарушения анимации. Некоторые страницы трудно читать. Основной ZIP использует оригинальный fallback. Провалившиеся новые geometry overrides, Reading Mode и Dream TimePitch API не включены.
- **UI:** принятые исправления длинных имён, скорости атаки, «Тип»/«Прокрутка», фильтра/сортировки и ячеек навыков включены в v0.3.0. В других состояниях и окнах переполнения ещё возможны; полная визуальная проверка не заявляется.
- **Магия — размещение:** принятые «Поток ж. III», «Слаб. стихий», формы 156–160 и ещё десять compact names включены. Полные описания сохранены; не каждый экран проверен.

## Неполнота

- **Магия:** русские значения доставляются для 152 из 153 непустых native ID (152 distinct school/name-pool identities; 110/132 — один Powera pool). Это не число доступных игроку уникальных заклинаний и не процент готовности. Из прежних 65 английских full/short конфликтов 64 получили русский текст. All-Stonus (45) остаётся английским: его короткая форма совпадает с All-Stone (180), но эффекты различаются. Все 50 native compound recipes имеют русские результаты и обе колонки компонентов. Общий key не поддерживает отдельные full/short по каждому экрану.
- Прежние одинаковые подписи «Изгнание» для Vanish/Lost относятся к разным школам; «Сила» у 110/132 разделяет один native name pool. Новые отдельные редакции не назначены.
- **Host UI:** шесть игровых TITLE-подписей переведены. Settings, первоначальная настройка и часть собственного интерфейса FreeFrank остаются английскими. В Game language выбирайте **Russian**: «Русский» в stock v1.0.4 отображается вопросами, игровые LOFONT не исправляют шрифт host UI.
- **Загрузка/сохранение:** 15 native сообщений добавлены, но отдельные profile notifications могут быть скрыты штатным ускорением меню. Два Lv в списке сохранений остаются без отдельной утверждённой привязки. Старые snapshot-названия мест в сохранениях могут остаться английскими; файлы сохранений не переписываются.
- **XMB:** 398 ключей доставлены, 539 дополнительных привязок отложены из-за 16-битного string pool. Некоторые локации остаются английскими; сохранённые snapshot-названия не переписываются.
- **Special:** наблюдавшийся главный боевой consumer ещё не доказан; одноимённые другие строки не подменялись по словарю.
- **Графика:** Perfect/Good/Bad, MISS/GUARD/DAMAGE GUARD/DELAY/DAMAGE UP, BATTLE-LOG и Loading не заменяются; ru-local-artwork не распространяется.
- В изменённых JSON сохраняются некоторые имена, латиница и части оригинального текста; это не полный английский экспорт и не 100% локализация. Кириллица italic-маршрута снов остаётся прямой; SUB timing и все поздние сцены отдельно не проверены.

Навыки с `%` исправлены в RU 0.5.1 и выборочно проверены владельцем. Шесть TITLE-подписей приняты, UI-FIT принят выборочно, новая магия утверждена для Beta. Это не полный игровой PASS: автоматические проверки четырёх дисков не заменяют визуальную проверку всех строк.

Русификатор предназначен для официального LostOdysseyRecomp от FreeFrank (Windows x64). Проверено в игре на официальном FreeFrank v1.0.6 для Windows x64. Основание — выборочная игровая проверка владельца; полное прохождение и проверка каждой строки не заявляются. Более новые версии пока не проверены и могут потребовать адаптации русификатора.

Имена врагов: проверены все1024 native slots (511 имён, включая171 каноническую шаблонную подпись «Монстр NNN»). Не утверждается, что каждый слот встречается в игре; при появлении шаблонной подписи сообщите имя и локацию.
