# Скриншоты / Screenshot provenance

Четыре кадра предоставлены владельцем проекта в архиве настоящих скриншотов FreeFrank.
Это готовые обрезки игрового окна: рабочий стол и другие приложения в них отсутствуют.
Файлы скопированы без изменения байтов. Генеративные изображения и кадры другого Recomp не использовались.
Версии взяты из приложенного владельцем манифеста; сам обрезанный кадр не показывает версию EXE.
Кадры подтверждают только видимый экран, а не проверку всех ресурсов или полного прохождения.

Кадры с дефектами снов/сохранений и дополнительные кадры из архива не включены.
