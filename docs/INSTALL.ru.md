# Установка — Windows x64 / FreeFrank

Русификатор предназначен для официального LostOdysseyRecomp от FreeFrank (Windows x64). Проверена работа на версии v1.0.4. Более новые версии могут быть совместимы, но пока не проверены. Обновления FreeFrank могут потребовать адаптации русификатора.

1. Получите официальный [FreeFrank для Windows x64](https://github.com/freefrank/LostOdysseyRecomp/releases/latest).
2. Самостоятельно подготовьте собственные оригинальные игровые данные по инструкции FreeFrank.
   Пакет не содержит дисков и не предоставляет права на их получение/копирование. Сначала убедитесь, что игра работает без русификатора.
3. Полностью закройте игру. Если уже есть `mods/ru`, перенесите всю старую папку в резервное место **за пределами `mods`**.
   Не объединяйте новый основной пакет со старым: оставшиеся Dream-файлы сохранят экспериментальные сны.
   Не оставляйте копию `language.ini` со вторым `id=ru` в другой подпапке `mods`.
4. Распакуйте основной `LostOdyssey-Russian-Language-Pack-v0.1.0-beta.zip` в папку с `LostOdysseyRecomp.exe`.
   Итоговый путь: `mods/ru/language.ini`, рядом `mods/ru/text`, `mods/ru/fonts`, `mods/ru/licenses`.
   Лишнего `mods/mods` или промежуточной папки с названием ZIP быть не должно.
5. Запустите игру. Откройте **Settings → System → Game language**, выберите **Русский** и сохраните настройку.
6. Полностью перезапустите игру: дополнительные глифы загружаются при запуске.
7. Загрузите существующее сохранение. Переносить/перезаписывать сохранения и достижения для установки языка не нужно.

Основной пакет сохраняет оригинальные сны. Экспериментальный ZIP с 34 русскими снами ставится отдельно,
поверх только что установленного основного пакета той же версии, в ту же папку игры; он имеет известные серьёзные наложения.
Это дополнение не самостоятельный language pack. См. `EXPERIMENTAL_DREAMS.md` в его архиве.

Если русского нет в списке: проверьте путь `mods/ru/language.ini`, отсутствие дубликатов `id=ru` и перезапуск.
Если остался английский текст, сравните с KNOWN_ISSUES; не заменяйте случайные игровые файлы.
Удаление: закройте игру, перенесите `mods/ru` за пределы `mods`, выберите другой язык и перезапустите.
Для возврата с экспериментальных снов на основной вариант замените **всю** `mods/ru` чистой основной папкой.
Языковой пакет не редактирует формат сохранений. Техническая установка проверена без игрового прохождения нового ZIP.
